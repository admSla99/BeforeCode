Proposed decisions this model encodes

One Question per turn, recorded by the agent. Each turn runs claude -p with --allowedTools "Bash(bfc ask:*)"; the agent records its Question with bfc ask --to <author>. When the turn ends the screen looks for the newest open Question from the AI to the author: found → it waits for your answer; not found → error "the turn ended without a recorded Question", Enter retries.
The TUI records your answer with the same code as bfc reply --verbatim (you, no agent), then starts the next turn with --resume <session> and your words.
Esc during a turn cancels it (the claude process is stopped). If the agent already recorded its Question, the screen waits for your answer; otherwise it is idle and Enter continues. Esc otherwise leaves to the plan detail; the session and any open Question stay, so the Grill pauses. Ctrl+C quits bfc, stopping a running turn first.
Session: the Claude session id is kept in .git/beforecode/grill/<plan ULID>.session. If it is missing or --resume fails, a new session starts from bfc prime grill <id>, which already holds every Question and answer, so nothing is lost. The file is removed once plan.md is written.
Sync keeps running. New Messages from others appear in the conversation with a notice. If the open Question is answered elsewhere (CLI, another clone), the input closes and Enter continues with the next turn. Messages are append-only, so sync never conflicts with the Grill.
Finishing: f asks the agent for its summary (an open Question stays open and is listed). Then w writes plan.md in one more turn with the write-plan skill, through bfc edit --stdin (allowed tool: bfc edit). If plan.md is already written, the screen asks you first; your yes is what lets the agent use --force. After saving, the screen returns to the plan detail on plan.md and the app syncs.
